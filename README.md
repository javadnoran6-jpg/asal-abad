# 🍯 عسل‌آباد — بازی آنلاین چت

بازی چندنفره‌ی لحظه‌ای: زنبورها در باغ راه می‌روند، چت می‌کنند، گل جمع می‌کنند و عسل می‌اندوزند. پنل مدیریت واقعی دارد.

## مرحله ۱: آنلاین کردن سرور (کاملاً با گوشی)
1. در github.com حساب بسازید و یک مخزن (Repository) جدید بسازید، مثلاً `asal-abad`.
2. محتوای همین zip را آپلود کنید (Add file ← Upload files؛ پوشه‌ها را هم بکشید/انتخاب کنید. اگر پوشه‌ی `.github` آپلود نشد، فایل `.github/workflows/build-apk.yml` را با Add file ← Create new file و همین مسیر دستی بسازید و متنش را کپی کنید).
3. به render.com بروید ← New ← Web Service ← مخزن را وصل کنید. Build Command: `echo ok` و Start Command: `node server.js`. در Environment متغیر `ADMIN_PASSWORD` را با رمز دلخواه خودتان بسازید.
4. بعد از چند دقیقه آدرسی مثل `https://asal-abad.onrender.com` می‌گیرید. بازی همان آدرس است و پنل مدیریت: `آدرس/admin`.

> نکته: پلن رایگان Render بعد از مدتی بی‌کاری می‌خوابد و داده‌ها (فایل db.json) پاک می‌شود. برای ماندگاری، Disk بخرید و `DATA_DIR` را روی مسیر آن بگذارید.

## مرحله ۲: ساخت APK با GitHub (بدون کامپیوتر)
1. در مخزن فایل `android/app/src/main/res/values/strings.xml` را باز کنید، آیکون مداد (Edit) را بزنید و `server_url` را به آدرس Render خودتان تغییر دهید. Commit کنید.
2. تب **Actions** ← workflow به نام *Build APK* به‌طور خودکار اجرا می‌شود (یا Run workflow بزنید). حدود ۳–۵ دقیقه.
3. پس از سبز شدن: از بخش **Releases** (سمت راست صفحه‌ی مخزن) فایل `app-debug.apk` را دانلود و نصب کنید.

## تغییر نام سازنده و تنظیمات
از `/admin` ← «تنظیمات بازی»: نام بازی، نام سازنده (الان: پریا چشم‌رنگی)، پیام خوش‌آمد، اتاق‌ها، کلمات ممنوع، فعال/غیرفعال کردن چت.

## اجرا روی کامپیوتر
`ADMIN_PASSWORD=رمز node server.js` سپس http://localhost:3000
